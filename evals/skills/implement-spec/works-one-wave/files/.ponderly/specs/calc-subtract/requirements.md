# Requirements Document

## Introduction

Add subtraction to the calc package so callers have the fourth basic operation.

## Glossary

- **Package**: The `calc` Python package.

## Requirements

### Requirement 1: Subtract

**User Story:** As a caller, I want `subtract(a, b)`, so that I can compute a minus b.

#### Acceptance Criteria

1. WHEN a caller calls `subtract(a, b)`, THE Package SHALL return a minus b.
2. THE Package SHALL cover `subtract` with a unit test in the existing test module.
